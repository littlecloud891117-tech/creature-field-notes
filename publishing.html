Editorial policy

Human choices stay in the story.

Tools can support drafting and production. A person makes material creative decisions before each episode becomes public.

Publication gate

Each episode receives a complete Traditional Chinese review copy. The reviewer changes or decides a character motive, relationship, dialogue, event result, or creature trait.

The English episode changes to match those decisions. The reviewer checks that final English text before publication.

Monetization

Advertisements are disabled. Affiliate links, if added later, will appear only on separate curated pages. Each such page will show a clear disclosure.
